# Donggri Visual V2 Character Batch Prompts

Use one prompt per actor or per small batch. Keep every output on a flat chroma-key background so the alpha pipeline can remove the background with `sharp`.

## Four-Direction Runtime Sprite Prompt

Create one chibi office-agent character for Dongri-grigri Visual V2 as a clean four-direction sprite sheet. Show the same character facing down/front, left, back/up, and right. Use three subtle walking frames per direction. Keep the body proportions, outfit colors, face, hair, and accessories consistent across all poses. Put every sprite on a flat chroma-key teal background, with no shadows touching the frame edge and no readable text.

## Portrait/Card Prompt

Create a crisp character portrait card image for Dongri-grigri Visual V2. Use a polished chibi office simulation style, expressive face, readable silhouette, and a UI-friendly background panel. No readable text, no logo, no watermark. Keep enough margin for card cropping.

## Office Prop Atlas Prompt

Create a game asset atlas of cozy modern office props for Dongri-grigri Visual V2. Include desks, chairs, monitors, plants, lamps, shelves, whiteboards, meeting tables, lounge seating, dashboard screens, and small decorative items. Use consistent pixel-isometric lighting, clean edges, and a flat chroma-key teal background.
