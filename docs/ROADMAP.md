# Roadmap

## Alpha candidate — implemented locally

- append-only checkpoint contract and SQLite storage
- Git workspace digest and drift gate
- bidirectional 40-case deterministic transfer fixtures
- provider readiness and fail-closed dispatch
- sequenced checkpoint WebSocket projection and snapshot recovery
- checkpoint-derived transit stations with fail-closed blocked states
- credential-free disposable-repository demo

## Alpha publication gates — pending

- exact commit and push approval
- atomic one-time approval consumption and source ownership/pause acknowledgement
- host-native Runner Supervisor binding and persisted run-event projection
- clean-clone Windows verification
- installable artifact and GitHub prerelease
- real Codex and Claude smoke evidence, at least 5 each
- public demo video

## Beta and Stable gates

Beta requires five independent external users, installation success at least 90%, browser/accessibility/reconnect evidence, and no P0/P1 findings. Stable requires at least 50 external handoffs with at least 95% success, all fail-closed fixtures passing, no known data loss, and README claims matching published behavior.
