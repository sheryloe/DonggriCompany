# Codex Execution Packages (Archive)

이 폴더는 `Step1~Step4` 시점의 실행 패키지 문서를 보관하는 아카이브입니다.

## 목적
- 루트 디렉터리 혼잡 제거
- 과거 실행 문서/태스크 카드 이력 보존
- 현재 런타임 코드(`apps/`, `packages/`)와 관심사 분리

## 포함 범위
- `step1-foundation-package`
- `step2-account-pools-router-package`
- `step3-employee-office-ui-package`
- `step4-telegram-bridge-package`

## 운영 원칙
- 아카이브 문서는 기본적으로 읽기 전용으로 유지
- 신규 구현/수정은 `apps/`, `packages/`, `docs/`(현행 문서)에서만 진행
