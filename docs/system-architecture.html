업무 오케스트레이션

$ directive와 # task registration은 프로젝트, 부서, 담당자, 실행기를 거쳐 추적 가능한 workflow로 변환된다.

Workflow engine 모듈

  • workflow/core.ts: CLI tool detection, context building, prompt blocks, WebSocket hub, common utilities.
  • workflow/agents.ts: agent profile, provider/model mapping, execution argument building.
  • workflow/orchestration.ts: planned meeting, task execution, review finalization, report workflow, subtask delegation.
  • routes/core/tasks/execution-run.ts: task run endpoint와 auto assignment 진입점.
  • routes/collab/*: cross-department cooperation, subtask routing, review/meeting coordination.

상태 흐름

inbox
  -> planned
  -> collaborating
  -> in_progress
  -> review
  -> done

interrupt/hold path:
pending, cancelled, stale assignment cleanup, watchdog recovery

Lifecycle watchdog는 in-progress orphan task, stale working agent, pending subtask delegation을 주기적으로 복구한다.
